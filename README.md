# Kandelo demos

Small programs that generate visuals and an interactive story inside a browser-local [Kandelo](https://kandelo.dev/) terminal. Each launch link carries the startup script in its compressed `#k1=` fragment; the operating system and Python load separately.

Open a demo below, or download and open [the HTML gallery](index.html) for the visual version with expandable startup scripts.

**Orbit / rotating donut** — A shaded ASCII torus rotates using perspective and a depth buffer.

**Chromatic / sine plasma** — Sine waves generate a shifting field of ANSI terminal colors.

**Seed / cellular life** — A seeded colony evolves through Conway’s Game of Life.

**Boundary / Mandelbrot** — A visual zoom loops inward and outward through a fixed range of Mandelbrot detail. Frames are calculated once and cached for replay; the iteration budget stays fixed to avoid increasingly slow, black frames. Press Ctrl+C to stop.

**The Last Process / text adventure** — Explore five rooms inside a dying computer, solve three puzzles, and choose how the story ends. Type `help` for commands, `hint` for a clue, or `quit` to exit.

The donut, plasma and Life animations finish automatically. Mandelbrot runs until Ctrl+C. All restore the terminal cursor on exit. The text adventure waits for typed commands. Reloading Kandelo resets the environment.

## Rebuild the gallery

Run with Python 3, using only the standard library:

```sh
python3 build.py
```

This regenerates `index.html`, `links.json`, and the four animation scripts. Animation source lives in `build.py`; the adventure source lives in `adventure.py`. The builder verifies that each encoded link decodes to the intended startup script. Rerun the builder after changing a demo, then update the README launch links and sizes from `links.json`.

URL sizes count UTF-8 bytes of the complete launch URL, including the compressed boot descriptor.

## Validation

The scripts and encoded links have been checked locally, including all three adventure endings. These demos have not yet been verified on the live Kandelo runtime.
